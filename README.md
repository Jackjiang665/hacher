# hacher · 个人智能工作台

hacher 是一个面向科研、研发和个人项目的 Windows 本地桌面工作台。它把任务、日程、项目、论文、电子元件、AI 记忆和 Agent 终端放在同一个界面中。

当前版本已经可以真实保存本地数据、调用千问、检索论文与网页资料、识别元器件截图，并在应用内运行 PowerShell 和 Claude Code。

## 核心能力

### AI 截图识别入库

在“电子元件库”中一次选择多张购买截图，千问视觉模型会提取元器件名称、分类、规格和数量，并写入本地库存。

- 支持一张图识别多个商品
- 重复图片自动跳过
- 同名同规格元件自动合并数量
- 低置信度结果标记为“待核对”
- 支持后续编辑、增减数量和低库存提醒

### 每日情报

添加“大模型不确定性”“具身智能”等关注主题后，hacher 会通过 arXiv API 搜索最新论文，并通过阿里云百炼获取可追溯的网页资料。

结果包含题目、作者、摘要、日期和原始链接。主题每天自动更新一次，也可以手动刷新。

### Agent 终端与长期记忆

应用内置真实 PowerShell 终端，可以启动本机已安装的 Claude Code。Claude 通过受控数据桥读取工作台中的任务、库存、记忆、项目、日程、论文和关注主题。

启动终端时会自动忽略未运行的本地代理端口；有效代理仍会正常继承。写入命令默认只预览，用户确认后才会真正执行。终端或 Agent 修改数据后，界面会自动同步。

长期记忆可以在“AI 记忆中心”手动维护，也可以在对话中通过“请记住……”添加。调用千问时，已确认的记忆会作为上下文使用。

## 功能一览

| 模块 | 当前功能 |
|:---|:---|
| 工作台总览 | 汇总任务、项目、日程和库存提醒 |
| 今日待办 | 新建与完成任务、筛选状态、统计完成率、AI 安排建议 |
| 日程安排 | 周时间轴、事件分类、编辑删除和时间冲突提示 |
| 项目中心 | 管理科研、创业、软件、电子、模型和 DIY 项目 |
| 论文与科研 | 导入、去重、打开和删除本地 PDF，实时检索 arXiv |
| 英语学习 | 创建计划、记录每日学习并统计累计时长 |
| 每日情报 | 管理关注主题，聚合最新论文和网页资讯 |
| 电子元件库 | 手动入库、AI 截图入库、库存管理和低库存提醒 |
| AI 记忆中心 | 查看、添加和删除长期记忆 |
| Agent 终端 | 内嵌 PowerShell、Claude Code 和工作台数据桥 |

## 下载与安装

前往 [Releases](https://github.com/Jackjiang665/hacher/releases/latest) 下载最新的 `hacher-setup-*.exe`。

安装程序支持选择固定安装目录，并会创建桌面和开始菜单快捷方式。目前只提供 Windows x64 版本。

## 配置千问

千问对话、联网搜索和截图识别需要用户自己的阿里云百炼 API Key：

1. 在阿里云百炼控制台创建 API Key；
2. 点击 hacher 左下角“我的工作区”右侧的三点按钮；
3. 打开“千问 API 设置”，填写 Key 和模型名称。

API Key 只保存在当前 Windows 用户的本机环境配置中，不会写入 GitHub 仓库或工作台数据文件。

## 数据与隐私

- 工作台数据：`%APPDATA%\hacher-workbench\hacher-data.json`
- 本地论文：`%APPDATA%\hacher-workbench\papers\`
- 升级或卸载应用不会主动删除工作台数据
- 任务、项目、库存和记忆默认只保存在本机
- 使用千问功能时，相关请求内容会发送给阿里云百炼

## 当前边界

- 暂不支持账号、云同步和多人协作
- PDF 论文库尚未自动解析全文或生成笔记
- DIY 项目目前使用通用项目结构，独立 BOM 和实验记录仍在开发
- hacher AI 默认只回答和建议，不会自行修改工作台数据
- Claude 终端需要本机另外安装并登录 Claude Code

## 从源码运行

需要 Node.js 18+ 和 Git。

```bash
git clone https://github.com/Jackjiang665/hacher.git
cd hacher
npm install --ignore-scripts
node tools/prepare-native.cjs
npm start
```

打包 Windows 安装程序：

```bash
npm run pack
```
