# hacher · 个人智能工作台

hacher 是一个面向科研、研发和个人项目的 Windows 本地桌面工作台。它把任务、日程、项目、论文、电子元件、AI 记忆和 Agent 终端放在同一个界面中。

当前版本已经可以真实保存本地数据、通过后台智能服务检索论文与网页资料、识别元器件截图，并在应用内运行 PowerShell 和 Claude Code。

## 核心能力

### AI 截图识别入库

在“电子元件库”中一次选择多张购买截图，后台视觉服务会提取元器件名称、分类、规格和数量，并写入本地库存。

- 支持一张图识别多个商品
- 重复图片自动跳过
- 同名同规格元件自动合并数量
- 低置信度结果标记为“待核对”
- 支持后续编辑、增减数量和低库存提醒

### 每日情报

添加“大模型不确定性”“具身智能”等关注主题后，hacher 会通过 arXiv API 搜索最新论文，并通过阿里云百炼获取可追溯的网页资料。

结果包含题目、作者、摘要、日期和原始链接。主题每天自动更新一次，也可以手动刷新；主页晨间简报会显示最近一次真实更新及来源数量。

### 项目资料与工作日志

每个项目都有独立工作页面，可以按电路图、BOM、原理图、3D 模型、软件代码、论文、合同和测试记录等分类整理文件。

- “复制进资料库”会在 hacher 本地项目库中保存副本
- “关联原文件”保留电脑上的原路径，不重复复制
- 工作日志分别记录已完成工作、改进、遗留问题和下一步
- 文件、日志和项目创建记录会自动汇总为时间线
- 任务、日程和本地论文可以关联到项目，并在各模块间同步显示
- 项目 BOM 会与元件仓库比较需求和库存，自动标记缺料
- 里程碑、问题与风险、方案决策可以独立跟踪

### Agent 终端与长期记忆

应用内置真实 PowerShell 终端，可以启动本机已安装的 Claude Code。Claude 通过受控数据桥读取工作台中的任务、库存、记忆、项目、日程、论文和关注主题。

启动终端时会自动忽略未运行的本地代理端口；有效代理仍会正常继承。写入命令默认只预览，用户确认后才会真正执行。终端或 Agent 修改数据后，界面会自动同步。

长期记忆在“Agent 记忆中心”手动维护，并通过本地数据桥提供给 Claude Agent。后台截图识别和情报检索不会读取长期记忆。

## 功能一览

| 模块 | 当前功能 |
|:---|:---|
| 工作台总览 | 汇总任务、项目、日程和库存提醒 |
| 今日待办 | 新建与完成任务、筛选状态和统计完成率 |
| 日程安排 | 周时间轴、事件分类、编辑删除和时间冲突提示 |
| 项目中心 | 完整项目页、任务与日程联动、论文、文件、日志、BOM、里程碑、问题和决策 |
| 论文与科研 | 导入、去重、打开和删除本地 PDF，实时检索 arXiv |
| 英语学习 | 创建计划、记录每日学习并统计累计时长 |
| 每日情报 | 管理关注主题，聚合最新论文和网页资讯 |
| 电子元件库 | 手动入库、AI 截图入库、库存管理和低库存提醒 |
| Agent 记忆中心 | 查看、添加和删除 Claude 可读取的长期记忆 |
| Agent 终端 | 内嵌 PowerShell、Claude Code 和工作台数据桥 |

## 下载与安装

前往 [Releases](https://github.com/Jackjiang665/hacher/releases/latest) 下载最新的 `hacher-setup-*.exe`。

安装程序支持选择固定安装目录，并会创建桌面和开始菜单快捷方式。目前只提供 Windows x64 版本。

## 配置后台智能服务

截图识别、论文检索词生成和每日情报需要用户自己的阿里云百炼 API Key：

1. 在阿里云百炼控制台创建 API Key；
2. 点击 hacher 左下角“我的工作区”右侧的三点按钮；
3. 打开“后台智能服务”，填写 Key 和模型名称。

支持旧版 `sk-` 和安全升级后的新版 `sk-ws-` API Key。

API Key 只保存在当前 Windows 用户的本机环境配置中，不会写入 GitHub 仓库或工作台数据文件。

## 数据与隐私

- 工作台数据：`%APPDATA%\hacher-workbench\hacher-data.json`
- 本地论文：`%APPDATA%\hacher-workbench\papers\`
- 项目资料库：`%APPDATA%\hacher-workbench\projects\`
- 自动备份：`%APPDATA%\hacher-workbench\backups\`
- 升级或卸载应用不会主动删除工作台数据
- 任务、项目、库存和记忆默认只保存在本机
- 使用截图识别、检索和情报整理时，相应请求内容会发送给阿里云百炼

## 当前边界

- 暂不支持账号、云同步和多人协作
- PDF 论文库尚未自动解析全文或生成笔记
- 项目已支持通用 BOM 与库存联动，Excel/供应商级 BOM 导入仍在开发
- Claude 终端需要本机另外安装并登录 Claude Code

## 从源码运行

需要 Node.js 18+ 和 Git。

```bash
git clone https://github.com/Jackjiang665/hacher.git
cd hacher
npm install --ignore-scripts
node tools/prepare-native.cjs
npm start
```

打包 Windows 安装程序：

```bash
npm run pack
```
